==================================================
OBSERVATION
==================================================

For the tested query "Bluetooth"/"bluetooth", both KMP and
Rabin-Karp successfully searched the complete text of the
20-product corpus.

Both algorithms identified the same 11 matching product files
and the same match positions.

The project verifies the consistency of the results returned
by the two algorithms.

KMP performs pattern matching using the LPS (Longest Proper
Prefix which is also Suffix) preprocessing technique.

Rabin-Karp performs pattern matching using a rolling hash and
character verification when hash values match.

The actual matching operation does not use String.contains()
or String.indexOf().
